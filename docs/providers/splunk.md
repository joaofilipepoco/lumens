# Splunk Observability Cloud

Use Splunk managed OTLP ingestion or a Splunk-supported ingestion component with `LUMENS_PROVIDER=splunk`. Provide the realm endpoint and access token through the standard endpoint and Lumens secret variables.

Verify realm, token scopes, logs availability, TLS, and supported component configuration against current Splunk documentation. Splunk dimensions and entity enrichment remain outside Lumens application code.
