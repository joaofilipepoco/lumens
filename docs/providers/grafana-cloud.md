# Grafana Cloud

Use Grafana Cloud managed OTLP ingestion with `LUMENS_PROVIDER=grafana-cloud`. Provide the stack endpoint and access-policy token through deployment configuration. The profile declares the provider's basic-auth style header mapping.

Verify the stack-specific endpoint, token format, signals, TLS, and access-policy scopes against current Grafana Cloud documentation. Grafana data-source labels remain provider configuration.
